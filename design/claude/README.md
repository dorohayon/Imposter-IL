# Claude Design exports

תיקייה זו מיועדת לקובצי המקור שיוצאו מ־Claude Design עבור **מי המתחזה?**.

הארכיון שסופק כולל:

- `Imposter IL Screens.dc.html` — 29 מסכים ומצבי מערכת ב־390×844.
- `Imposter IL Design System.dc.html` — צבעים, טיפוגרפיה ורכיבים.
- `Imposter IL Prototype.dc.html` — זרימות Prototype לחיצות.
- `support.js` — קובץ התמיכה של הייצוא.

מקורות האמת למוצר הם `docs/`, `CLAUDE.md` ו־`TASKS.md`. קובצי ה־HTML הם תוצר עיצובי ואינם רשאים לשנות חוקי משחק.

> קובצי הייצוא עצמם יתווספו לכאן ללא שינוי לאחר שסביבת העבודה תוכל לחלץ את ארכיון המקור. נכסי הדמויות והאילוסטרציות כבר נמצאים תחת `assets/` ומחוברים גם לאפליקציית Flutter.
