# מי המתחזה?

אפליקציית משחק חברתי בעברית שבה כל השחקנים מקבלים מילה סודית, מלבד המתחזה. כל שחקן כותב רמז בתורו, הקבוצה מצביעה, ואם המתחזה נתפס הוא מקבל הזדמנות אחרונה לנחש את המילה.

המאגר הוא monorepo: אפיון ועיצוב תחת `docs/`, `design/` ו־`assets/`, אפליקציית Flutter תחת `app/`, ושרת Go תחת `server/`.

## סטטוס

- מצב מילה: באפיון
- Wireframe: גרסה מעודכנת עם 29 מסכים ומצבי מערכת
- מצב שאלה: מחוץ ל־MVP ויתוכנן בהמשך
- כיוון עיצובי: נקבע; 12 אווטארים ו־11 אילוסטרציות בגרסת v1 נמצאים תחת `assets/`
- שרת Go: שלד עם `/healthz` ומנוע משחק ראשון עם Unit Tests
- Flutter: Prototype UI לחיץ ב־RTL עם נתוני דמה; אינו מחובר לשרת, אינו שומר נתונים, ומעטפות Android/iOS והפונטים טרם נוספו

## אפליקציית Flutter

נדרש Flutter 3.27.0 ומעלה (Dart 3.6). ה־CI מריץ `flutter analyze` ו־`flutter test` גם על גרסת המינימום וגם על stable, ובדיקת פורמט על stable.

```sh
cd app
flutter pub get
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```

מעטפות Android/iOS עדיין אינן במאגר. כדי להריץ על מכשיר או סימולטור יש ליצור אותן מקומית עם `flutter create --platforms=android,ios .` ואז `flutter run`, בלי לבצע commit לקבצים שנוצרו.

### מה עובד, מה דמה ומה פתוח

ה־Client הוא Prototype לחיץ. הוא אינו מחובר לחוזי ה־REST וה־WebSocket שב־`docs/protocol.md`.

**UI שעובד מקומית:** ניווט בין כל המסכים, כפתור חזרה בכל מסך שאינו מסך משחק, יציאה מהמשחק בפינה הימנית העליונה, בחירת כינוי ואווטאר, בחירת קטגוריות, בדיקות רמז בצד הלקוח (מילה אחת, עד 25 תווים, מילה סודית ורמז כפול מבין הרמזים שכבר נחשפו), הסתרת המילה מהמתחזה, הצבעה ללא הצבעה עצמית ושינוי בחירה עד סוף הזמן, שדה קוד חדר של שש ספרות עם שגיאה בתוך המסך, הסרת שחקנים ועדכון מונה השחקנים בלובי, העתקת קוד החדר, ו־`משחק נוסף` שחוזר לבחירת קטגוריות או ללובי.

**נתוני דמה (`app/lib/demo/`):** שחקנים, סדר תורות, תפקידים, קטגוריות, המילה `בננה`, רמזי השחקנים האחרים, תוצאת ההצבעה, חלוקת הקולות וקוד החדר `482731`. הטיימרים הם `DemoCountdown` מקומי שמקדם את ה־Prototype כשהזמן נגמר; באפליקציה המחוברת הספירה תחושב לפי `deadline` מהשרת ורק השרת יקדם שלבים. אין באפליקציה פעולה שמאפשרת לשחקן להתחיל משחק ברשת.

**מצבים שרק השרת מפעיל:** משחק כמתחזה, הצבעה חוזרת, אין התאמה לקטגוריות, חיבור מחדש, הוצאה לאחר הניתוק השלישי, סיום בגלל מחסור בשחקנים ותקלה בשרת. בגרסת debug אפשר לפתוח אותם מהכפתור `מצבי Prototype (debug)` במסך הבית. הכפתור אינו מופיע בגרסת release.

**פתוח:** חיבור לשרת, שמירת זהות, הגדרות, ניצחונות והפסדים, הפונטים Secular One ו־Rubik, מעטפות Android/iOS, חסימת כינוי לא ראוי, נעילת הגדרות החדר, העברת מנהל, שיתוף מערכת של קוד החדר, עריכת פרופיל, תנאי שימוש ומדיניות פרטיות (מוצגים כלא זמינים), וכללי נרמול עברית לבדיקת רמזים וניחושים (שאלה פתוחה; ה־Prototype משווה התאמה מדויקת בלבד).
