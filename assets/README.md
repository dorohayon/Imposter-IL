# נכסי איור

גרסת `v1` של שפת הדמויות והאיורים עבור `מי המתחזה?`.

כל הנכסים:

- נוצרו באותה שפת איור בלשית צבעונית.
- כוללים רקע שקוף אמיתי (`RGBA`).
- אינם כוללים טקסט, כדי שהטקסט העברי יישאר רכיב UI נגיש וניתן לעריכה.
- משתמשים בפלטת המוצר: כחול־כהה, צהוב, טורקיז, קורל, סגול וקרם.
- מיועדים לשימוש חוזר; אין ליצור מחדש דמות עבור מצב selected, disconnected או eliminated.

### שימוש ב־UI

- בחירה או רשימת שחקנים: להציג בתוך מסכה עגולה או rounded square.
- גודל מינימלי מומלץ: `48×48`; גודל מועדף ברשימות: `56–64`.
- מצב selected: מסגרת צהובה וסימן בחירה.
- מצב disconnected: שקיפות חלקית ותג חיבור.
- מצב eliminated: גוון אפור ותג הדחה.
- אין לערוך את קובץ הדמות עבור המצבים האלה.
