# שפות — איך מוסיפים שפה

המשחק כולו תומך בכמה שפות (`docs/decisions.md`, "שפות"). שפה היא נתונים, לא קוד:

| מה | איפה | מה יש בו |
| --- | --- | --- |
| תוכן המשחק | `server/internal/content/languages/<code>.json` | 21 קטגוריות ו־1,000 מושגים, 8 רמזי בוט ישירים לכל מושג, רמזי מתחזה, כתיבים חלופיים לניחוש, ארבע הודעות תגובה, שמות ורמזים לבוטים |
| ממשק האפליקציה | `app/lib/l10n/app_<code>.arb` | כל הטקסטים, כולל `languageName` — שם השפה בשפה עצמה. `app_he.arb` הוא התבנית |
| שם האפליקציה מתחת לאייקון | `app/ios/Runner/<code>.lproj/InfoPlist.strings`, `app/android/app/src/main/res/values-<code>/strings.xml` | `CFBundleDisplayName` / `app_name` |

## הוספת שפה

1. להעתיק את `languages/en.json` ל־`languages/<code>.json` ולכתוב את התוכן. **לא לתרגם מילה במילה** — להתאים את המילים תרבותית, תוך שמירה על 21 מזהי הקטגוריות המשותפים לרכישות ולמעבר שפה. אפשר להוסיף קטגוריות מקומיות לשפה אחת (כמו `israeli_slang` בעברית), כל עוד לפחות קטגוריה חינמית אחת קיימת בכל שפה.
2. `cd server && go test ./internal/content/` — הבדיקות אוכפות את כל הכללים: 1,000 מושגים ייחודיים בכתב אחד, רמזים שהמנוע יקבל ושלא מסגירים את המילה, רמזי מתחזה שלא מסגירים אף מילה בקטגוריה, שמות קטגוריה ייחודיים בין השפות, הקטגוריות החינמיות, אותם מזהי תגובות ובוטים שלמים.
3. `go run ./cmd/exportwords` — מעדכן את המילים של המשחק במכשיר אחד באפליקציה.
4. להוסיף `app/lib/l10n/app_<code>.arb` (העתק של `app_en.arb`, מתורגם). השפה מופיעה מעצמה בהגדרות.
5. שם האפליקציה: `<code>.lproj/InfoPlist.strings` (ולרשום אותו ב־Xcode, בקבוצה `InfoPlist.strings`), הקוד ב־`CFBundleLocalizations` שב־`Info.plist`, ו־`values-<code>/strings.xml` ב־Android (עברית: `values-iw`).
6. `flutter test` ו־`go test ./...`.
7. דפי החנויות, האתר (`site/`) ותנאי השימוש ומדיניות הפרטיות בשפה — בבדיקה של בעל המוצר.

## מה משותף לכל השפות

- **חוקי הרמזים** (`server/internal/game/words.go`): נרמול, חסימת מילה סודית בתוך רמז ורמז כפול. אותיות השימוש והאותיות הסופיות של עברית אינן משפיעות על כתב אחר. שפה שתצטרך קיפול ניקוד או אקסנטים תוסיף אותו שם, עם מקרים ב־`testdata/word_rules.json`.
- **מילים חסומות** (`server/internal/content/blocked_words.txt`): רשימה אחת לכל השפות, לכינויים ולרמזים — קללה בעברית אסורה גם במשחק באנגלית.
- **מזהי קטגוריות ומוצרים:** רכישה שייכת למזהה, בכל שפה שיש בה אותה קטגוריה. פרימיום פותח הכול בכל השפות.

## באפליקציה

- **בחירת השפה:** שפת הטלפון, או מה שנבחר בהגדרות (`settings.language`). שפה שאין לאפליקציה — אנגלית. כיוון המסך (RTL/LTR) נגזר מהשפה.
- **טקסט בקוד:** בווידג'טים `context.l10n.<key>` — כך המסך נבנה מחדש כשהשפה מתחלפת. בקוד בלי `BuildContext` (מפות שגיאות, פונקציות עזר) — `l10n` הגלובלי, בתוך getter ולא בקבוע, כדי שלא יישמר בשפה הקודמת.
- **אין לוגיקה על טקסט:** החלטה לפי תוכן מחרוזת ("מכיל את המילה…") נשברת בשפה אחרת. דגל, קוד או תפקיד — לא טקסט.
- **בדיקות:** `test/flutter_test_config.dart` קובע עברית לכל הבדיקות; `test/english_test.dart` מריץ את האפליקציה באנגלית, כולל כל המסכים שמחוץ למשחק ב־320px.

## בשרת

כל בקשה שתלויה בתוכן נושאת `language` (`docs/protocol.md`); בלעדיה `he`, כדי שגרסאות ישנות ימשיכו לעבוד. לכל חדר שפה קבועה, והיא קובעת את המילים, התגובות והבוטים. חיפוש משחק מתאים רק שחקנים באותה שפה.
