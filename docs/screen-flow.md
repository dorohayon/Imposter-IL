# מפת המסכים

## כניסה

`כניסה ראשונה` → `מסך הבית`

## משחק ברשת

`מסך הבית` → `בחירת משחק ברשת`

משם:

- `משחק מהיר` → `בחירת קטגוריות` → `חיפוש שחקנים`.
- `חדר פרטי` → `יצירת חדר` או `הצטרפות לחדר` → `לובי פרטי`.

שתי הזרימות ממשיכות אל `חשיפת תפקיד` → `שלב הרמזים` → `הצבעה`.

לאחר ההצבעה:

- אזרח הודח והמתחזה עדיין במיעוט → `סבב רמזים נוסף`
- אזרח הודח ונוצר שוויון מספרי → `תוצאת ניצחון למתחזה`
- המתחזה נתפס → `ניחוש המתחזה`
  - ניחוש נכון → `תוצאת ניצחון למתחזה`
  - ניחוש שגוי או פקיעת זמן → `תוצאת ניצחון לאזרחים`
- תיקו → `הכרזה על תיקו` → `הצבעה חוזרת`
  - תיקו נוסף → `הכרזה על תיקו חוזר` → `סבב רמזים נוסף` ללא הדחה
- הצבעה ללא קולות → `סבב רמזים נוסף`; פעם שנייה ברצף → `המשחק בוטל`

ממסך התוצאה:

- `משחק נוסף` → שמירת השחקנים שבחרו להמשיך והשלמת שחקנים חסרים
- `יציאה` → `מסך הבית`

## משחק במכשיר אחד

`מסך הבית` → `משחק במכשיר אחד` → `שחקנים` → `חוקי המשחק` → `חלוקת תפקידים`
→ `סבב רמזים` → `הצבעה פרטית` → `חשיפת המודח`.

אחרי החשיפה:

- אזרח הודח והמתחזה עדיין במיעוט → סבב רמזים נוסף.
- המתחזה הגיע לשוויון מספרי → תוצאת ניצחון למתחזה.
- המתחזה הודח → ניחוש מילה → תוצאה.
- תיקו → הכרזה משותפת על תיקו → מסך פרטיות והצבעה חוזרת; תיקו נוסף → הכרזה משותפת → סבב חדש ללא הדחה.

הזרימה המלאה והבדלי האופליין נמצאים ב־`docs/local-game-design.md`.

## מסכי משנה

- `פרופיל` נפתח ממסך הבית.
- `הגדרות` נפתח ממסך הבית.
- `איך משחקים?` נפתח ממסך הבית.
- `חיבור מחדש` מוצג מעל מסך המשחק בזמן ניתוק.
- `הוצאה מהמשחק` מוצג לאחר הניתוק השלישי.
- `שגיאת הצטרפות` מוצג כאשר קוד חדר אינו תקין או שהחדר אינו זמין.
- `תקלה בשרת` מוצג כאשר לא ניתן להמשיך את המשחק; לא נרשם הפסד.
